# NextShop – Full-Stack Next.js E-commerce Demo

A modern, responsive e-commerce demo application built with **Next.js (App Router)**, **NextAuth.js**, and a simple **Express.js backend**.  
This project features public and protected pages, authentication, product management, and a polished UI.

---

## Features
- Fully responsive landing page with hero and multiple sections
- Public & protected routes
- Authentication with Google login (NextAuth.js)
- Add and manage products (protected pages)
- Item listing and details pages
- Clean, consistent, and modern UI
- Express.js backend serving product data
- Easy deployment to Vercel

---

## Tech Stack
- **Next.js 14 (App Router)**
- **NextAuth.js** for authentication
- **React** for UI
- **TailwindCSS** for styling
- **Express.js** for backend API
- Optional database (MongoDB / JSON storage)
